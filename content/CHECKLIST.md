# Pre-upload checklist

Run through this before every video goes out.

## Every long-form
- [ ] Outro names **next week's episode** (Bit says it, and its thumbnail fills the "next video" box). Only fall back to the Bit's Arcade playlist card if the next episode isn't decided.
- [ ] Once the next episode is live, swap the previous long-form's end-screen element to it.
- [ ] Viewer question in the outro and description (feeds "you pick what Bit builds next").
- [ ] Chapters, game links and prompt link in the description.
- [ ] Pinned comment ready.
- [ ] 2 to 3 Shorts cut from it, each with the long-form set as Related video.

## Before rendering any voiced video
- [ ] Check every line is in the right voice (Bit vs Glitch) against the script; the lip-sync follows the script, not the audio.

## Every Short / Ask Bit episode
- [ ] Ends by naming the next episode ("Next time on Ask Bit: …") plus a follow/subscribe line.
- [ ] Related video set to the matching long-form.
- [ ] Comment call to action (e.g. "Comment GAME") and a pinned comment.
- [ ] Posted to TikTok and Instagram the same day.

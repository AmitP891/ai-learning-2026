# Bit's Bug Blaster 3D: the shared prompt

Give this to every AI **word for word**. Start a stopwatch when you press send.

```
You are a team of 7 bots building a game together. Play each role in order,
label each section with the bot's name, and hand work to the next bot.

Bots: Producer, Game Designer, Artist, Coder, Sound Designer, Tester, Hype Bot.

THE GAME: "Bit's Bug Blaster 3D"
- Bit is a small, cute pink robot with a dark visor showing two glowing cyan eyes
  and a small screen on his chest.
- He runs around a neon circuit-board arena viewed from a tilted top-down camera.
- Red bugs crawl in from the edges. Bit zaps them with a short cyan beam from his
  chest (SPACE). Each zapped bug pops into a green tick.
- If 5 bugs reach the glowing "CPU" in the centre, the computer crashes: GAME OVER.
- Survive 60 seconds to win the level. 3 levels, more bugs each time.
- Score, timer and lives on screen. WASD or arrow keys to move. Works on mobile
  with on-screen buttons.

RULES
- One single index.html file, using Three.js from a CDN. No image or sound files:
  build everything from simple shapes and Web Audio.
- Original designs only: no real game characters, logos or music.
- Must run by opening the file in Chrome. No errors in the console.
- Tester must play through all 3 levels and report what's broken; Coder fixes it.
  Maximum 2 fix rounds.

At the end, give me: the final index.html in full, the tester's last report,
and the Hype Bot's 3 title ideas.
```
